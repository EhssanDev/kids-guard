# Kids Guard

Single-phone parental app blocker. An accessibility service watches which app is in the foreground
and sends the child back to the home screen when a blocked app opens.

- Per-app rules: always allowed / always blocked / allowed only in a time window / temporary allowance
- Parent PIN (PBKDF2) required to open the app and change anything
- Device admin to make uninstalling harder; optional protection of Settings / package installer
